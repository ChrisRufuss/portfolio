# INSTRUCTIONS: ADDING YOUR RESUME
Place your official resume PDF in this directory with the file name:
`resume.pdf`

Path: `public/assets/resume.pdf`

Once you place the file here:
1. Open `src/data/portfolio.js`
2. Under `personalInfo.resume`, change:
   `enabled: false` to `enabled: true`
3. Save the file. The "Resume" download button will immediately appear in your Hero section!
